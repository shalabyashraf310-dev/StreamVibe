# StreamVibe 🎬

**StreamVibe** is a modern media and movie streaming platform inspired by Netflix, built with React and Vite.

## ✨ Features

- Modern and responsive user interface.
- Movie and TV show sections.
- Featured hero section.
- Movie cards and content rows.
- Clean and user-friendly design.

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS
- Vite

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/shalabyashraf310-dev/StreamVibe.git
   ```

2. Navigate to the project folder:

   ```bash
   cd StreamVibe
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
